About Me

Senior Software Engineer & System Architect with deep enterprise system experience.

Hello, I'm a Senior Software Engineer & System Architect

歡迎來到我的個人作品空間。我是一位深耕新竹科學園區的資深軟體工程師，具備近二十年的企業系統開發經驗，專長涵蓋程式開發、系統分析（SA）、系統設計（SD）、資料庫開發與企業流程整合，是一位能同時兼顧技術實作與系統架構的全方位工程師。

我的職涯橫跨 Workflow、ERP、資料庫程式設計。我擅長將複雜的企業需求，轉化為清楚的系統規格、具整合性與可擴充性的系統架構。

在專案開發過程中，我不只負責程式撰寫，也參與需求訪談、流程分析、系統設計、資料表規劃、Business Logic 開發與文件規格撰寫，能從完整軟體生命週期的角度思考與解決問題。

工作之外，我熱衷於羽球與登山。這些運動讓我維持良好的體能、穩定的心理素質與持續的專注力，使我在面對高壓的開發環境、複雜的系統問題與長時間的系統維運時，依然能保持良好的續航力與抗壓性。

我熱愛學習新技術，並持續關注人工智慧、機器學習與資料分析等領域的發展。目前正在國立中興大學進修 Python 相關的 AI 人工智慧與數據分析應用課程，透過系統化的學習，強化 Python 程式設計、資料處理、資料視覺化、機器學習模型與實務專題開發能力。
